1. Registrasi dan Login

Penjelasan alur

  1. Mulai — Pengguna membuka aplikasi.
  2. Sudah punya akun? — Jika Belum, pengguna diarahkan ke Halaman Registrasi. Jika Sudah, pengguna langsung menuju Halaman Login.
  3. Halaman Registrasi dan Input Data Registrasi — Pengguna baru mengisi data yang diminta.
  4. Data valid? — Jika Tidak, sistem menampilkan error lalu pengguna kembali ke Halaman Registrasi. Jika Ya, sistem menyimpan akun pembeli lalu pengguna menuju Halaman Login.
  5. Halaman Login dan Input Username dan Password — Pengguna memasukkan username dan password.
  6. Validasi? — Jika Tidak, sistem menampilkan error lalu pengguna kembali ke Halaman Login. Jika Ya, sistem memeriksa role.
  7. Role? — Pembeli menuju Alur Pembeli (bagian 2), Admin menuju Alur Admin (bagian 3).
Registrasi hanya tersedia untuk pembeli. Akun admin disiapkan oleh pengembang sistem.

2. Alur Pembeli

Penjelasan alur

  1. Halaman Katalog Akun — Pembeli melihat daftar akun game yang tersedia.
  2. Cari atau Filter Akun — Pembeli mencari akun dan memfilter berdasarkan game atau harga.
  3. Pilih Akun dan Lihat Detail — Pembeli membuka detail akun yang diminati.
  4. Akun masih tersedia? — Sistem memastikan akun belum terjual sebelum order dibuat. Jika Tidak, sistem menampilkan pesan akun terjual lalu pembeli kembali ke katalog. Jika Ya, pembelian dilanjutkan.
  5. Klik Beli dan Buat Order Pending — Order dibuat dengan status pending saat pembeli menekan tombol Beli.
  6. Proses Pembayaran Simulasi — Sistem memproses pembayaran dalam mode simulasi.
  7. Pembayaran sukses? — Jika Tidak, order dibatalkan lalu pembeli kembali ke katalog. Jika Ya, sistem melanjutkan ke pembaruan status.
  8. Update Order Paid dan Akun Terjual — Status order menjadi paid dan status akun menjadi terjual.
  9. Tampilkan Detail Akun Hasil Pembelian — Data login akun hanya ditampilkan setelah pembayaran berhasil.
  10. Simpan ke Riwayat Pesanan — Transaksi disimpan ke database dan dapat dilihat di riwayat pesanan.
  11. User Logout? — Jika Tidak, pembeli kembali ke katalog dan dapat membeli akun lain. Jika Ya, alur berakhir pada Selesai.

3. Alur Admin

Penjelasan alur

  1. Login sebagai Admin — Admin masuk ke aplikasi.
  2. Dashboard Admin — Sistem menampilkan halaman utama admin.
  3. Pilih Menu — Admin memilih Kelola Akun atau Lihat Pesanan.
  4. Jalur Kelola Akun — Admin menambah, mengubah, atau menghapus akun game, lalu sistem memvalidasi data input. Jika data tidak valid, sistem menampilkan error dan admin kembali memperbaiki data. Jika valid, data disimpan ke database.
  5. Jalur Lihat Pesanan — Sistem menampilkan daftar pesanan, lalu admin memfilter pesanan berdasarkan status.
  6. Logout? — Kedua jalur bertemu di sini. Jika Tidak, admin kembali ke Dashboard Admin. Jika Ya, alur berakhir pada Selesai.

4. Diagram Alur Data

Penjelasan alur

  1. Buka katalog — Browser mengirim GET /api/akun ke Flask Backend, yang mengambil akun berstatus tersedia dari database lalu mengembalikannya sebagai JSON untuk ditampilkan sebagai katalog.
  2. Klik Beli — Browser mengirim POST /api/order. Backend mengecek status akun dan menyimpan order dengan status pending di database.
  3. Pembayaran — Backend meminta pembayaran simulasi diproses. Jika statusnya sukses, backend memperbarui order menjadi paid dan akun menjadi terjual.
  4. Tampil kredensial — Backend mengirim detail akun dalam bentuk JSON, lalu browser menampilkan data login akun kepada pembeli. Data ini hanya tampil setelah status order paid.
